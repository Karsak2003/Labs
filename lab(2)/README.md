
## Metallurgy Graph Builder (`lab(2)\main.py`)

### 📖 Описание

Построение графа информационно-аналитических веб-ресурсов металлургической промышленности РФ и ближнего зарубежья. Связи между ресурсами устанавливаются через общие ключевые термины, извлечённые из текстов страниц.

### 📄 Файл `urls.txt`

Создайте текстовый файл со списком URL (минимум 25 ресурсов):

```
https://www.metalinfo.ru/
https://www.metalloinvest.com/
https://www.nlmk.com/
https://www.severstal.com/
# ... и т.д.
```

### 🚀 Использование

```bash
python lab(2)\main.py URLS_FILE [опции]
```

#### Аргументы

| Аргумент | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `input_file` | позиционный | ✅ | Путь к файлу со списком URL |
| `--parser` | выбор | ❌ | Парсер BS4: `html.parser`, `lxml` (по умолчанию), `html5lib` |
| `--threshold` | число | ❌ | Минимум общих терминов для ребра (по умолчанию: 3) |
| `--top-n` | число | ❌ | Топ-N терминов с каждой страницы (по умолчанию: 50) |
| `--render/--no-render` | флаг | ❌ | Рендерить граф (по умолчанию: ДА) |
| `--format` | выбор | ❌ | Формат рендеринга: `pdf` (по умолчанию), `svg`, `png` |
| `--output` | строка | ❌ | Базовое имя выходного файла (по умолчанию: `metallurgy_graph`) |
| `--timeout` | число | ❌ | Таймаут HTTP-запроса в секундах (по умолчанию: 15) |
| `--delay` | число | ❌ | Задержка между запросами (по умолчанию: 0.5 сек) |

### 📋 Примеры

```bash
# Базовый запуск
python 'lab(2)\main.py' urls.txt

# С выбором парсера
python 'lab(2)\main.py' urls.txt --parser html5lib

# Без рендеринга (только DOT-файл)
python 'lab(2)\main.py' urls.txt --no-render

# Рендер в SVG с низким порогом
python 'lab(2)\main.py' urls.txt --threshold 2 --format svg

# Полный пример
python 'lab(2)\main.py' urls.txt \
    --parser lxml \
    --threshold 3 \
    --top-n 50 \
    --render \
    --format pdf \
    --output my_graph \
    --timeout 20 \
    --delay 1.0
```

### 📊 Выходные файлы

| Файл | Содержимое | Сохраняется |
|------|-----------|-------------|
| `*.dot` | Исходный DOT-код графа | **Всегда** |
| `*.pdf` | Визуализация графа | Если `--render` |
| `*.svg` | SVG-визуализация | Если `--format svg --render` |
| `*.png` | PNG-визуализация | Если `--format png --render` |

### ⚠️ Возможные проблемы

- **Сайты блокируют запросы** — увеличьте `--delay` до 1-2 секунд
- **Некоторые сайты на JS** — `requests` не работает с JS-рендерингом, нужен Selenium
- **Мало терминов** — уменьшите `--threshold` до 2
- **Слишком плотный граф** — увеличьте `--threshold` до 5
- **Системный graphviz не найден** — установите пакет `graphviz` через пакетный менеджер ОС
- **Менее 25 ресурсов** — добавьте больше URL в `urls.txt`
