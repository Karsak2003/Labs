# 🔬 Лабораторная работа №2: Граф металлургических веб-ресурсов

## 🎯 Цель работы

Построить **граф информационно-аналитических веб-ресурсов**, посвящённых металлургической промышленности РФ и ближнего зарубежья. Связи между ресурсами устанавливаются через **пересечение ключевых терминов**, извлечённых из текстов страниц.

**Минимальный размер графа:** 25 ресурсов.

---

## Стек технологий

| Компонент | Библиотека | Назначение |
|-----------|-----------|------------|
| HTTP-клиент | `requests` | Загрузка HTML-страниц |
| Парсер HTML | `BeautifulSoup4` | Извлечение текста (с выбором парсера) |
| Морфология | `pymorphy3` + `razdel` | Лемматизация и извлечение терминов |
| Визуализация | `graphviz` | Построение и рендеринг графа |
| CLI | `argparse` | Интерфейс командной строки |
| Прогресс | `tqdm` | Индикатор прогресса |

> **Важно:** в исходной лекции указан `rutermextract`, но он несовместим с Python 3.11+ (ошибка `inspect.getargspec`). В данной реализации используется замена на `pymorphy3` + `razdel` с собственной логикой извлечения терминов.

---

## Требования

- **Python** 3.10 или новее
- **Системный Graphviz** (бинарь `dot`):
  - **Windows:** `choco install graphviz` или [скачать с graphviz.org](https://graphviz.org/download/)
  - **Ubuntu/Debian:** `sudo apt install graphviz`
  - **macOS:** `brew install graphviz`

## Установка

1. **Клонируйте/скопируйте проект** и перейдите в его каталог:
   ```bash
   cd lab2
   ```

2. **Создайте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv .venv
   .venv\Scripts\activate    # Windows
   # source .venv/bin/activate  # Linux/macOS
   ```

3. **Установите зависимости:**
   ```bash
   pip install requests beautifulsoup4 lxml html5lib pymorphy3 razdel graphviz tqdm
   ```

4. **Создайте файл `urls.txt`** со списком URL (минимум 25), по одному на строку:
   ```
   https://www.metalloinvest.com/
   https://www.nlmk.com/
   https://www.severstal.com/
   https://www.magnitogorsk.com/
   https://www.evraz.com/
   ...
   ```

---

## Использование

### Базовый запуск

```bash
python main.py urls.txt
```

### Примеры команд

```bash
# 1. С выбором парсера lxml (рекомендуется)
python main.py urls.txt --parser lxml --threshold 3

# 2. С парсером html5lib (самый точный, но медленный)
python main.py urls.txt --parser html5lib

# 3. Без рендеринга графа (только DOT-файл)
python main.py urls.txt --no-render

# 4. Рендер в SVG
python main.py urls.txt --render --format svg

# 5. Рендер в PNG с низким порогом (больше рёбер)
python main.py urls.txt --threshold 2 --format png

# 6. Полный пример со всеми параметрами
python main.py urls.txt \
    --parser lxml \
    --threshold 3 \
    --top-n 50 \
    --render \
    --format pdf \
    --output metallurgy_graph \
    --timeout 20 \
    --delay 1.0
```

## Аргументы CLI

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `input_file` | позиционный | — | Путь к файлу со списком URL |
| `--parser` | `html.parser` / `lxml` / `html5lib` | `lxml` | Парсер BeautifulSoup |
| `--threshold` | int | `3` | Мин. число общих терминов для ребра |
| `--top-n` | int | `50` | Сколько топ-терминов брать с каждой страницы |
| `--render / --no-render` | флаг | `render` | Рендерить граф в файл |
| `--format` | `pdf` / `svg` / `png` | `pdf` | Формат рендеринга |
| `--output` | str | `metallurgy_graph` | Базовое имя выходного файла |
| `--timeout` | int | `15` | Таймаут HTTP-запроса, сек |
| `--delay` | float | `0.5` | Задержка между запросами, сек |

## Алгоритм работы

```
┌──────────────────────────────────────────────────────────┐
│  1. Чтение URL-ов из файла                               │
└──────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────┐
│  2. Для каждого URL:                                     │
│     • requests.get() — загрузка страницы                 │
│     • BeautifulSoup — парсинг HTML                       │
│     • Извлечение текста из p, h1-h6, li, article         │
│     • pymorphy3 + razdel — извлечение терминов           │
└──────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────┐
│  3. Построение графа:                                    │
│     • Узлы = ресурсы (домены)                            │
│     • Рёбра = пересечение терминов ≥ threshold           │
│     • Толщина ребра пропорциональна числу общих терминов │
└──────────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────────┐
│  4. Сохранение:                                          │
│     • DOT-файл — ВСЕГДА                                  │
│     • PDF/SVG/PNG — если --render                        │
└──────────────────────────────────────────────────────────┘
```

## Возможные проблемы

### 1. `AttributeError: module 'inspect' has no attribute 'getargspec'`
**Причина:** `rutermextract` использует `pymorphy2`, несовместимый с Python 3.11+.  
**Решение:** использовать `pymorphy3` + `razdel` (реализовано в данной версии).

### 2. `graphviz.backend.execute.ExecutableNotFound`
**Причина:** системный `dot` не установлен.  
**Решение:** установить Graphviz (см. раздел [«Требования»](#Требования)).

### 3. Сайт блокирует запросы (403)
**Причина:** сайт защищает от ботов.  
**Решение:** увеличить `--delay`, использовать прокси или исключить URL из списка.

### 4. Слишком плотный/разреженный граф
**Решение:** изменить `--threshold` (2–5) или `--top-n` (30–100).
