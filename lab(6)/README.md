## 📖 Обзор

Консольное приложение `topic_modeling.py` реализует пайплайн **векторного анализа веб-данных**: от загрузки сырого корпуса до тематического моделирования и кластеризации. Приложение поддерживает два режима работы:

1. **`topic`** — тематическое моделирование (LDA / NMF) с автоматическим подбором числа тем через coherence score
2. **`cluster`** — кластеризация объектов (например, городов по кулинарным предпочтениям) тремя методами с визуализацией

Приложение написано на Python 3.11+ с использованием `argparse`, `scikit-learn`, `gensim`, `matplotlib` и `pandas`.

## 💻 CLI-интерфейс

Приложение использует **подкоманды** (`topic`, `cluster`) для разделения режимов работы.

```bash
python topic_modeling.py <command> [аргументы]
python topic_modeling.py --help
python topic_modeling.py <command> --help
```

### Подкоманда `topic`

Тематическое моделирование корпуса документов.

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--dataset` | `str` | **обязателен** | Путь к JSON/CSV с документами |
| `--text-field` | `str` | `text` | Имя поля с текстом в JSON/CSV |
| `--method` | `str` | `lda` | Метод: `lda`, `nmf`, `both` |
| `--topics` | `int\|auto` | `auto` | Число топиков или `auto` для подбора |
| `--n-features` | `int` | `1000` | Размер словаря (max_features) |
| `--n-top-words` | `int` | `10` | Топ-слов на топик для визуализации |
| `--min-docs` | `int` | `50` | Минимальное число документов |
| `--output` | `str` | **обязателен** | Префикс выходных файлов |

#### Примеры

```bash
# LDA с автоподбором K
python topic_modeling.py topic 
    --dataset demo_news.json --method lda --topics auto 
    --output news_lda

# NMF с фиксированным K=5
python topic_modeling.py topic 
    --dataset demo_news.json --method nmf --topics 5 
    --n-top-words 15 --output news_nmf

# Сравнение LDA и NMF на одном датасете
python topic_modeling.py topic 
    --dataset demo_news.json --method both --topics 5 
    --output compare
```

### Подкоманда `cluster`

Кластеризация объектов (по умолчанию — демо-матрица «город × блюдо»).

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--input` | `str` | — | Путь к CSV/JSON с матрицей (опционально) |
| `--k` | `int` | `3` | Число кластеров |
| `--output` | `str` | **обязателен** | Префикс выходных файлов |

#### Примеры

```bash
# Демо-кластеризация
python topic_modeling.py cluster --k 3 --output cities_demo

# По своей матрице (CSV: строки=города, столбцы=блюда)
python topic_modeling.py cluster \
    --input cities_dishes.csv --k 4 --output cities_real
```

## 🧠 Алгоритмы

### LDA (Latent Dirichlet Allocation)

**Тип:** вероятностная генеративная модель  
**Вход:** матрица счётчиков (CountVectorizer)  
**Выход:** распределение слов по темам + распределение тем по документам

**Принцип:** каждый документ — смесь тем, каждая тема — распределение по словам. Параметры априорного распределения Дирихле (`alpha`, `eta`) управляют разреженностью.

**Параметры по умолчанию:**
- `passes=15` (число проходов по корпусу)
- `iterations=100`
- `alpha='auto'`, `eta='auto'`
- `random_state=42`

### NMF (Non-negative Matrix Factorization)

**Тип:** алгебраическое разложение  
**Вход:** TF-IDF матрица  
**Выход:** разложение DTM ≈ W × H

**Принцип:** минимизация невязки `‖X − WH‖` при ограничениях `W ≥ 0, H ≥ 0`. Быстрее LDA, детерминирован при фиксированном seed.

**Параметры по умолчанию:**
- `max_iter=200`
- `random_state=42`

### Кластеризация

Реализованы три метода (sklearn):

| Метод | Класс | Метрика | Особенности |
|-------|-------|---------|-------------|
| K-Means | `KMeans` | Евклидова | Быстрый, сферические кластеры |
| Иерархическая | `AgglomerativeClustering` | Ward | Дендрограмма, не требует K заранее |
| Спектральная | `SpectralClustering` | Косинусная | Ловит нелинейные структуры |

Перед кластеризацией применяется **L2-нормализация** (`sklearn.preprocessing.normalize`) — сравниваем пропорции, а не абсолютные значения.

## 📐 Метрики качества

### Coherence score (c_v)

Мера согласованности слов внутри топика. Вычисляется через `gensim.models.CoherenceModel` на основе скользящего окна по корпусу и нормализованной точечной взаимной информации (NPMI).

- **Диапазон:** −1 … 1
- **Хорошие значения:** 0.4 … 0.65
- **Меньше 0.3:** топики, скорее всего, мусорные

**Использование:** перебор K от 3 до 20, выбор K с максимальным coherence.

### Silhouette score

Мера того, насколько объект похож на свой кластер по сравнению с соседними.

- **Диапазон:** −1 … 1
- **> 0.5:** разумная кластеризация
- **> 0.7:** сильная структура

### Метод локтя (Elbow method)

График inertia (сумма квадратов расстояний до центроидов) от K. «Локоть» — точка, после которой прирост inertia замедляется.

## 🛠 Устранение неисправностей

### Ошибка: `Failed building wheel for gensim`

**Причина:** Python 3.13/3.14 не поддерживается.  
**Решение:**
```bash
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install gensim
```

### Ошибка: `Resource stopwords not found`

**Решение:**
```python
import nltk
nltk.download('stopwords')
```

### График coherence пустой

**Причина:** все значения coherence = NaN (обычно из-за малого словаря или ошибки в модели).  
**Решение:**
- Уменьшите `--n-features` до 500
- Убедитесь, что в корпусе > 100 документов
- Проверьте, что после предобработки остались непустые тексты

### Мало документов (< 50)

LDA/NMF требуют минимум 50–100 документов для стабильной работы. На меньшем объёме топики будут случайными.

### Топики содержат стоп-слова («и», «в», «на»)

**Причина:** неполный словарь стоп-слов.  
**Решение:** добавьте доменные стоп-слова в функцию `remove_stopwords()`.
