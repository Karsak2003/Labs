
# 📚 Лабораторные работы по курсу «Интеллектуальный анализ веб-данных»

Данный репозиторий содержит выполненные лабораторные работы по курсу «Интеллектуальный анализ веб-данных». Каждая работа представляет собой законченный программный модуль с собственным CLI-интерфейсом, документацией и примерами использования.

## 🔬 Список лабораторных работ

Ниже приведен список всех выполненных работ с кратким описанием и ссылками на подробную документацию внутри каждой папки.

| № | Название работы | Краткое описание | Документация |
|---|-----------------|------------------|--------------|
| **1** | **Поиск по архиву Common Crawl** | Консольное приложение для поиска страниц в веб-архиве через CDX-индекс с опциональной загрузкой текста из WARC-файлов по HTTP-заголовку `Range`. | [📖 lab(1)/README.md](https://github.com/Karsak2003/Labs/blob/main/lab(1)/README.md) |
| **2** | **Граф веб-ресурсов** | Построение графа информационно-аналитических веб-ресурсов (металлургическая промышленность) на основе пересечения ключевых терминов, извлечённых из текстов страниц. | [📖 lab(2)/README.md](https://github.com/Karsak2003/Labs/blob/main/lab(2)/README.md) |
| **3** | **Wikimedia Data Collector** | Автоматизированный сборщик данных из экосистемы Wikimedia (Википедия, Викиданные, Викисловарь, Commons) с адаптивным rate limiting, batch-запросами и построением графа связей. | [📖 lab(3)/README.md](https://github.com/Karsak2003/Labs/blob/main/lab(3)/README.md) |
| **4** | **Лабораторная работа №4** | Дополнительные материалы и код в соответствии с тематикой курса. | [📖 lab(4)/README.md](https://github.com/Karsak2003/Labs/tree/main/lab(4)) |
| **5** | **NLP-анализ веб-данных** | Обработка естественного языка, анализ текстовых данных веб-ресурсов. | [📖 lab(5)/README.md](https://github.com/Karsak2003/Labs/tree/main/lab(5)) |
| **6** | **Векторный анализ веб-данных** | Тематическое моделирование (LDA / NMF) с автоматическим подбором числа тем через coherence score, а также кластеризация объектов. | [📖 lab(6)/README.md](https://github.com/Karsak2003/Labs/blob/main/lab(6)/README.md) |
| **7** | **Анализ видеоданных** | Система автоматического анализа и семантической обработки видеоданных: детекция объектов (YOLO), транскрипция речи (Whisper), извлечение метаданных (yt-dlp, ffprobe) и тематическая группировка. | [📖 lab(7)/README.md](https://github.com/Karsak2003/Labs/blob/main/lab(7)/README.md) |
| **8** | **Рекомендательные системы** | Реализация алгоритмов рекомендательных систем для веб-данных. | [📖 lab(8)/README.md](https://github.com/Karsak2003/Labs/tree/main/lab(8)) |

> 💡 **Рекомендация:** Перед запуском любой лабораторной работы обязательно ознакомьтесь с её индивидуальным `README.md`, так как некоторые работы требуют установки системных зависимостей (например, `Graphviz` или `ffmpeg`).

## 🚀 Общие инструкции по запуску

Для работы с лабораторными работами рекомендуется использовать виртуальное окружение Python.


### 3. Установка зависимостей
Перейдите в папку конкретной лабораторной работы и установите её зависимости. Например, для первой работы:
```bash
cd lab(1)
pip install -r requirements.txt  # если файл присутствует, или см. инструкции в README.md
```
> ⚠️ **Важно:** Некоторые работы (например, №2, №3, №7) требуют предварительной установки системных пакетов (`graphviz`, `ffmpeg`). Подробные инструкции указаны в соответствующих разделах документации.
