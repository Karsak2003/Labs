## 1. Постановка задачи

Разработать систему автоматического анализа и семантической обработки
видеоданных с поиском по значимым событиям.

### Блок 1 — Обработка видео

- Сбор видео с хостингов и локальных файлов
- Извлечение метаданных (`yt-dlp`, `ffprobe`)
- Декомпозиция: кадры, аудио, метаданные
- Подготовка данных для мультимодального анализа

### Блок 2 — Семантический анализ

- Визуальные характеристики: объекты (детекция YOLO)
- Аудио: речь, транскрипт с временными метками (Whisper)
- Временные паттерны: события с метками времени
- Тематическая группировка роликов

### Обязательные выходные артефакты

| № | Артефакт | Где в реализации |
|---|----------|------------------|
| 1 | Ключевые визуальные характеристики и объекты | `visual_events` в `<id>_analysis.json` |
| 2 | Временные метки значимых событий | `timeline` + команда `timeline` |
| 3 | Статистика по распознанным сущностям | счётчики объектов в логе `analyze`, `clusters.csv` |
| 4 | Интерактивная временная шкала | команды `timeline` и `search` (переход по времени) |
| 5 | Тематические распределения контента | команда `cluster` → `clusters.json` / `clusters.csv` |

## 2. Архитектура

```
Сбор            Декомпозиция       Анализ видео      Анализ аудио
yt-dlp     →    ffmpeg / OpenCV →  YOLO (Ultralytics) Whisper
(видео+мета)    (кадры, аудио)     (объекты)         (транскрипт)
                                        ↓                 ↓
                                Временная шкала событий
                                (build_timeline)
                                        ↓
                                Группировка по темам
                                (TF-IDF + KMeans)
                                        ↓
                                Интерфейс: search / timeline
                                (переход к моменту по времени)
```

Каждый этап сохраняет результат на диск — тяжёлые модели не нужно
перезапускать ради повторного анализа.

### Соответствие команд этапам пайплайна

| Этап | Команда | Ключевые функции |
|------|---------|------------------|
| Сбор + метаданные | `download` | `download_video()`, `get_video_metadata_ffprobe()` |
| Декомпозиция | `analyze` (шаги 1–2) | `get_video_metadata_ffprobe()`, `extract_audio()` |
| Визуальный анализ | `analyze` (шаг 3) | `detect_objects_in_frames()` |
| Аудио анализ | `analyze` (шаг 4) | `transcribe_audio()` |
| События | `analyze` (шаг 5) | `build_timeline()` |
| Группировка | `cluster` | `cluster_videos()` |
| Поиск и шкала | `search`, `timeline` | `search_events()`, `cmd_timeline()` |

## 3. Стек технологий

| Инструмент | Роль | Этап |
|------------|------|------|
| `yt-dlp` | Скачивание видео и метаданных с хостингов | Сбор |
| `ffmpeg` / `ffprobe` | Декодирование, извлечение аудио (mono 16 kHz), тех. метаданные | Декомпозиция |
| `OpenCV` (`opencv-python`) | Потоковое чтение кадров с привязкой ко времени | Декомпозиция |

| `scikit-learn` | TF-IDF + KMeans для тематической группировки | Группировка |
| `pandas`, `numpy` | Табличный экспорт, агрегация | Вывод |
| `tqdm` | Прогресс-бары длительных операций | Все этапы |
| `argparse` | CLI с подкомандами | Интерфейс |

## 4. Установка

### Требования

- Python **3.10+**
- `ffmpeg` в `PATH` (обязательно — используются и `ffmpeg`, и `ffprobe`)
- ~2 ГБ свободного места под модели и данные (минимум)
- GPU не обязателен, но ускоряет Whisper в разы

### Python-зависимости

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

pip install yt-dlp ultralytics openai-whisper opencv-python \
            scikit-learn pandas tqdm numpy
```

### Системный ffmpeg

```bash
# Ubuntu / Debian
sudo apt install ffmpeg

# macOS
brew install ffmpeg

# Windows (winget)
winget install Gyan.FFmpeg
# либо скачать сборку с https://ffmpeg.org/download.html
# и добавить папку bin в PATH
```

Проверка:

```bash
ffmpeg -version
ffprobe -version
```

### Первый запуск: загрузка весов моделей

Модели скачиваются автоматически при первом обращении:

| Модель | Размер (прибл.) | Когда скачивается |
|--------|-----------------|-------------------|
| `yolov8n.pt` | ~6 МБ | Первый `analyze` |
| Whisper `tiny` | ~75 МБ | При выборе `--whisper-model tiny` |
| Whisper `base` | ~145 МБ | Первый `analyze` (по умолчанию) |
| Whisper `small` | ~465 МБ | При выборе `--whisper-model small` |
| Whisper `medium` | ~1.5 ГБ | При выборе `--whisper-model medium` |
| Whisper `large` | ~2.9 ГБ | При выборе `--whisper-model large` |

### Рекомендации по железу (Whisper)

| Модель | VRAM (прибл.) | Комментарий |
|--------|---------------|-------------|
| `tiny` / `base` | ~1 ГБ | Работает на CPU, старт для учебных задач |
| `small` | ~2 ГБ | Заметно лучше качество русского языка |
| `medium` | ~5 ГБ | Желателен GPU |
| `large` | ~10 ГБ | Только GPU, для финальных прогонов |

> Для тестов работоспособности использовать модели `tiny` / `base` или `small`.

### Оценка объёма данных

Ориентир из лекции: 1080p при 8 Мбит/с ≈ **3,5 ГБ за час** видео.
Планируйте диск заранее; для длинных роликов уменьшайте `--fps-sample`.

## 6. Справочник CLI

Общий вид:

```bash
python video_analyzer.py <команда> [аргументы]
```

Коды возврата: `0` — успех, `1` — ошибка (файл не найден, нет данных и т.п.).

### 6.1 `download` — сбор видео и метаданных

```bash
python video_analyzer.py download URL [-o OUTPUT_DIR]
```

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `url` | позиционный | — | URL ролика (YouTube, Rutube, VK Video и др.) |
| `-o`, `--output-dir` | строка | `data/videos` | Папка для видео и метаданных |

Создаёт: `<id>.<ext>`, `<id>_meta.json` (включая блок `technical` от ffprobe).

### 6.2 `analyze` — полный анализ одного видео

```bash
python video_analyzer.py analyze VIDEO [-o OUTPUT_DIR] [опции]
```

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `video` | позиционный | — | Путь к видеофайлу |
| `-o`, `--output-dir` | строка | `data/analysis` | Папка результатов |
| `--fps-sample` | float | `1.0` | Кадров в секунду для выборки (`0.5` = кадр раз в 2 с) |
| `--conf` | float | `0.4` | Порог уверенности YOLO |
| `--yolo-model` | строка | `yolov8n.pt` | Модель YOLO |
| `--whisper-model` | выбор | `base` | `tiny` / `base` / `small` / `medium` / `large` |
| `--language` | строка | `ru` | Язык аудио (задаётся явно, чтобы не тратить время на автоопределение) |
| `--keywords` | строка | — | Ключевые слова через запятую для аудио-событий на шкале |

Создаёт: `<id>_audio.wav`, `<id>_analysis.json`.

Шаги внутри команды:
1. Технические метаданные (`ffprobe`)
2. Извлечение аудио (`ffmpeg`, mono 16 kHz) — пропускается, если аудиодорожки нет
3. Детекция объектов по выборке кадров
4. Транскрипция Whisper
5. Построение временной шкалы (`build_timeline`)

> **Важно:** аудио-события попадают на шкалу только при переданном
> `--keywords`. Полный транскрипт сохраняется в `transcript` всегда.

### 6.3 `cluster` — тематическая группировка

```bash
python video_analyzer.py cluster ANALYSIS_DIR [--k N]
```

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `analysis_dir` | позиционный | — | Папка с файлами `*_analysis.json` |
| `--k` | int | `5` | Число кластеров (автоматически ограничивается числом видео) |

Метод: TF-IDF (`max_features=5000`) по названию + описанию + транскрипту,
затем KMeans (`random_state=42`, `n_init=10`).
Создаёт: `clusters.json`, `clusters.csv`.

### 6.4 `search` — поиск по событиям

```bash
python video_analyzer.py search ANALYSIS_DIR --query QUERY [--limit N] [--youtube-links]
```

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `analysis_dir` | позиционный | — | Папка с результатами анализа |
| `--query` | строка | обязательный | Поисковый запрос |
| `--limit` | int | `20` | Максимум результатов в выдаче |
| `--youtube-links` | флаг | выкл. | Печатать ссылки с таймкодом для перехода к моменту |

Ищет подстроку в транскрипте (русский текст) и в именах классов объектов
(**английские** классы COCO: `person`, `car`, `bicycle`, …).

### 6.5 `timeline` — временная шкала одного видео

```bash
python video_analyzer.py timeline ANALYSIS_FILE [--limit N] [--output FILE]
```

| Аргумент | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `analysis_file` | позиционный | — | Путь к `<id>_analysis.json` |
| `--limit` | int | `50` | Максимум событий в выводе |
| `--output` | строка | — | Сохранить шкалу в отдельный JSON |

Обозначения в консоли: `●` — визуальное событие, `◆` — аудио (ключевое слово).

## 7. Быстрый старт и примеры

### Минимальный прогон на одном локальном файле

```bash
python video_analyzer.py analyze lecture.mp4 -o data/analysis/ \
    --keywords "интеграл,производная"
python video_analyzer.py timeline data/analysis/lecture_analysis.json
```

### Скачать ролик и проанализировать

```bash
python video_analyzer.py download "https://www.youtube.com/watch?v=dQw4w9WgXcQ" -o data/videos/
python video_analyzer.py analyze data/videos/dQw4w9WgXcQ.mp4 -o data/analysis/ \
    --keywords "ремонт,плитка,клей"
```

### Пакетная обработка (bash)

```bash
for f in data/videos/*.mp4; do
    python video_analyzer.py analyze "$f" -o data/analysis/ \
        --keywords "тема1,тема2" || echo "SKIP: $f" >> errors.log
done
```

### Пакетная обработка (PowerShell)

```powershell
Get-ChildItem data\videos\*.mp4 | ForEach-Object {
    python video_analyzer.py analyze $_.FullName -o data\analysis\ --keywords "тема1,тема2"
}
```

### Полный пайплайн на 5+ роликах (требование задания)

```bash
# 1. Сбор
python video_analyzer.py download "URL_1" -o data/videos/
python video_analyzer.py download "URL_2" -o data/videos/
python video_analyzer.py download "URL_3" -o data/videos/
python video_analyzer.py download "URL_4" -o data/videos/
python video_analyzer.py download "URL_5" -o data/videos/

# 2. Анализ каждого (см. цикл выше)

# 3. Группировка по темам
python video_analyzer.py cluster data/analysis/ --k 3

# 4. Поиск события
python video_analyzer.py search data/analysis/ --query "плитка" --youtube-links

# 5. Шкала конкретного ролика
python video_analyzer.py timeline data/analysis/XXXX_analysis.json --limit 30
```

### Англоязычное видео

```bash
python video_analyzer.py analyze talk.mp4 -o data/analysis/ \
    --language en --whisper-model small --keywords "python,tutorial"
```

### Длинное видео (экономия времени)

```bash
python video_analyzer.py analyze long_lecture.mp4 -o data/analysis/ \
    --fps-sample 0.5 --whisper-model tiny --conf 0.5
```

## 8. Форматы выходных файлов

### 8.1 `<id>_meta.json` (после `download`)

```json
{
  "id": "XXXX",
  "url": "https://www.youtube.com/watch?v=XXXX",
  "title": "Название ролика",
  "description": "Описание...",
  "duration": 212,
  "upload_date": "20240115",
  "view_count": 150000,
  "like_count": 4200,
  "comment_count": 310,
  "categories": ["Howto & Style"],
  "tags": ["ремонт", "плитка"],
  "local_file": "data/videos/XXXX.mp4",
  "technical": {
    "codec": "h264",
    "width": 1920,
    "height": 1080,
    "fps": 30.0,
    "duration": 212.06,
    "bit_rate": 2500000,
    "has_audio": true,
    "size_mb": 63.4
  }
}
```

> Поля статистики (`like_count`, `comment_count`) могут отсутствовать на
> стороне платформы — код везде использует `.get()` с дефолтом.

### 8.2 `<id>_analysis.json` (после `analyze`)

```json
{
  "id": "XXXX",
  "file": "data/videos/XXXX.mp4",
  "technical": { "codec": "h264", "width": 1920, "height": 1080,
                 "fps": 30.0, "duration": 212.06, "has_audio": true },

  "visual_events": [
    {
      "time": 12.0,
      "frame_idx": 360,
      "objects": [
        { "class": "person", "conf": 0.91, "bbox": [102.3, 48.7, 410.2, 603.5] }
      ]
    }
  ],

  "transcript": [
    { "start": 15.3, "end": 19.8, "text": "сейчас наносим клей на плитку" }
  ],

  "timeline": [
    { "time": 12.0, "type": "visual",
      "description": "Обнаружены: person",
      "objects": ["person"], "confidence": 0.91 },
    { "time": 15.3, "type": "audio",
      "description": "Ключевые слова: плитка — \"сейчас наносим клей...\"",
      "matched_keywords": ["плитка"],
      "text": "сейчас наносим клей на плитку", "confidence": 1.0 }
  ]
}
```

Пояснения к полям:

| Поле | Смысл |
|------|-------|
| `visual_events[].time` | Время кадра в секундах (рассчитано от fps конкретного ролика) |
| `visual_events[].objects[].bbox` | Рамка `[x1, y1, x2, y2]` в пикселях |
| `visual_events` | Содержит и кадры без объектов (`objects: []`) — для полноты ряда |
| `timeline` | Только значимые события: непустые кадры + совпадения ключевых слов |
| `transcript[].start/end` | Интервал сегмента речи по Whisper |

### 8.3 `clusters.csv` (после `cluster`)

```csv
id,title,cluster,topic_words
XXXX,,0,"плитка, клей, ремонт, ванная, затирка"
YYYY,,1,"интеграл, производная, функция, предел, график"
```

### 8.4 Экспорт шкалы (`timeline --output`)

```json
{ "title": "XXXX", "timeline": [ /* события, отсортированные по времени */ ] }
```

## 9. Обоснование выбора моделей и порогов

Этот раздел — обязательный пункт критериев оценки («обоснованность выбора
моделей и порогов»). Значения по умолчанию подобраны как компромисс
«качество / скорость на CPU»; при защите работы объясните свой выбор.

| Параметр | Значение | Обоснование | Альтернатива |
|----------|----------|-------------|--------------|
| YOLO-модель | `yolov8n.pt` | Самая лёгкая, работает на CPU, 80 классов COCO покрывают типовые объекты | `yolov8s/m` — точнее, но медленнее |
| Порог `--conf` | `0.4` | Баланс: ниже — ложные срабатывания, выше — пропуски | `0.25` для recall, `0.6` для precision |
| Выборка `--fps-sample` | `1.0` | Кадр раз в секунду — рекомендованный в лекции компромисс; шаг считается от fps **каждого** ролика | `0.5` для длинных видео, `2.0` для быстрых событий |
| Whisper | `base` | Работает на CPU, приемлемое качество русской речи | `small` — заметный прирост качества |
| Аудиоформат | mono, 16 kHz | Формат, на котором Whisper работает лучше всего | — |
| Язык `--language` | `ru` явно | Экономит время автоопределения и avoids ошибок на коротких роликах | `en` и др. по данным |
| Кластеризация | TF-IDF + KMeans | Быстрый интерпретируемый старт (топ-слова кластера) | LDA/NMF, HDBSCAN — см. лекцию 6 |
| `max_features` TF-IDF | `5000` | Ограничение словаря: скорость и устойчивость на малом корпусе | 1000–10000 |

## 14. Диагностика проблем

| Симптом | Причина | Решение |
|---------|---------|---------|
| `ffprobe не доступен` / `FileNotFoundError` | ffmpeg не в PATH | Установите ffmpeg, перезапустите терминал |
| Whisper очень медленный | CPU + большая модель | `--whisper-model tiny` или GPU-версия PyTorch |
| YOLO не находит объекты | Порог высок / классов нет в COCO | Снизьте `--conf` до 0.25; проверьте список классов модели |
| Пустой транскрипт | Нет речи / нет аудиодорожки | Проверьте `has_audio` в `technical`; это музыка/шум |
| `yt-dlp` не скачивает | Изменения на платформе | `pip install -U yt-dlp` |
| Ошибка ffmpeg на пути с кириллицей | Кодировка путей | Переместите файлы в путь без кириллицы/пробелов |
| `scraped 0` / пустые `visual_events` | Кодек не читается OpenCV | Перекодируйте: `ffmpeg -i in.mkv -c:v libx264 out.mp4` |
| Кластеризация не работает | < 2 видео | Проанализируйте больше роликов |
| Долгое видео «съедает» память | — | Кадры читаются потоком; уменьшите `--fps-sample` |
| HTTP 429 при download | Rate limit платформы | Пауза между загрузками, ограниченный набор роликов |

**Проверка после каждого запуска**: смотрите лог,
откройте результат, убедитесь, что данные не пустые и осмысленные.
